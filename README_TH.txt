==================================================================
 โปรแกรมสร้างป้ายสามเหลี่ยม (Word) — Mail Merge
==================================================================

โปรแกรมนี้ช่วยกรอก ชื่อ / ตำแหน่ง / หน่วยงาน แล้วสร้างไฟล์ Word
ป้ายตั้งสามเหลี่ยม (พับเป็นปริซึม อ่านได้ 2 ด้าน) โดยใช้ template เดิม
ของคุณ จึงรักษาเลย์เอาต์ ฟอนต์ (TH SarabunPSK) และการหมุนข้อความ 180°
ไว้ครบทุกอย่าง

------------------------------------------------------------------
 วิธีเริ่มใช้ (ครั้งแรกครั้งเดียว)
------------------------------------------------------------------
1) ติดตั้งไลบรารีที่ต้องใช้ — เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:

       py -3.12 -m pip install -r requirements.txt

   (เครื่องนี้ติดตั้งให้เรียบร้อยแล้ว ขั้นตอนนี้ทำไว้สำหรับย้ายไปเครื่องอื่น)

------------------------------------------------------------------
 วิธีเปิดโปรแกรม
------------------------------------------------------------------
* ดับเบิลคลิก  run.bat        -> เปิดโปรแกรม (หน้าต่างกรอกข้อมูล)
* ถ้าเปิดไม่ขึ้น/ปิดเอง ให้ดับเบิลคลิก  run_debug.bat  เพื่อดูข้อความ error

------------------------------------------------------------------
 ทำเป็นไฟล์ .exe (แจกให้เครื่องอื่นใช้โดยไม่ต้องลง Python)
------------------------------------------------------------------
* ดับเบิลคลิก  build_exe.bat   -> รอสร้างสักครู่
* ได้ไฟล์  dist\TriangleSign.exe  -> คัดลอกไป copy ใช้ที่เครื่องอื่นได้เลย
  (เครื่องปลายทางควรมี Microsoft Word + ฟอนต์ TH Sarabun สำหรับพรีวิว/PDF/พิมพ์)
* ไฟล์ที่สร้างจะอยู่ในโฟลเดอร์ output\ ข้าง ๆ ไฟล์ .exe

------------------------------------------------------------------
 วิธีใช้งาน
------------------------------------------------------------------
1) เลือก "แบบป้าย"
   - แบบ 1: ชื่อ + ตำแหน่ง/หน่วยงาน
   - แบบ 2: ชื่ออย่างเดียว (อเนกประสงค์)

2) เลือก "โหมด"
   - ทีละคน:  กรอกข้อมูลในช่อง
   - นำเข้ารายชื่อ:  กดปุ่ม "Choose Excel/CSV…" เลือกไฟล์รายชื่อ
                     * ดับเบิลคลิกที่ช่องในตารางเพื่อแก้ไขได้เลย
                     * ปุ่ม "➕ เพิ่มคน" / "🗑 ลบที่เลือก" จัดการรายชื่อได้
                     * เลือก "รวมไฟล์เดียว" หรือ "แยกไฟล์ต่อคน"

3) กดปุ่มที่ต้องการ
   - 🔍 Preview       : ดูภาพป้ายก่อนบันทึก
                        (โหมดนำเข้ารายชื่อ ใช้ปุ่ม ◀ ▶ เหนือพรีวิวเลื่อนดูคนอื่นได้
                         ภาพที่ดูแล้วจะถูกจำไว้ กลับมาดูซ้ำได้ทันที)
   - 💾 Save .docx    : เลือกที่เก็บแล้วบันทึกไฟล์ Word
   - 📝 Open in Word  : สร้างแล้วเปิดใน Word ให้แก้ไข/ตรวจ/พิมพ์เอง
   - 📄 Export PDF    : สร้างเป็นไฟล์ PDF
   - 🖨 Print         : เลือกเครื่องพิมพ์ที่ต้องการ แล้วสั่งพิมพ์

------------------------------------------------------------------
 รูปแบบไฟล์รายชื่อ (โหมดนำเข้า)
------------------------------------------------------------------
- ไฟล์ Excel (.xlsx) หรือ CSV
- แถวแรกเป็นหัวคอลัมน์ ใช้ได้ทั้งไทยและอังกฤษ เช่น
      name | position | org
      ชื่อ | ตำแหน่ง | หน่วยงาน
- แบบ 2 ใช้แค่คอลัมน์ชื่อ
- ดูตัวอย่างได้ที่ไฟล์  sample_list.xlsx

------------------------------------------------------------------
 โครงสร้างไฟล์ในโฟลเดอร์
------------------------------------------------------------------
  app.py            หน้าต่างโปรแกรม (GUI)
  merge_engine.py   เติมข้อมูลลง template -> .docx
  word_io.py        เชื่อม Word: เปิด/PDF/พิมพ์/พรีวิว
  data_io.py        อ่าน Excel/CSV
  templates\        ไฟล์ต้นแบบ 2 แบบ (สำเนามาจากของเดิม — แก้ดีไซน์ที่นี่ได้)
  output\           ไฟล์ที่สร้างออกมา
  sample_list.xlsx  ตัวอย่างไฟล์รายชื่อ
  run.bat           ดับเบิลคลิกเพื่อเปิดโปรแกรม

------------------------------------------------------------------
 หมายเหตุ
------------------------------------------------------------------
- ป้าย 1 หน้า = 1 คน (มีข้อความ 4 จุดสำหรับการพับ ทุกจุดเป็นชื่อเดียวกัน)
- อยากแก้ดีไซน์/ขนาดตัวอักษร/โลโก้ ให้แก้ที่ไฟล์ในโฟลเดอร์ templates\
  โดยคงข้อความ «name» และ «pos» (merge field) ไว้
- ฟีเจอร์ PDF/พิมพ์/พรีวิวรูป ต้องมี Microsoft Word ติดตั้งในเครื่อง
