UI Redesign — แนวทาง C

ปรับโครงสร้างเดิม (panel เดียว) ให้ scroll น้อยลง และ ดูเป็นระเบียบ

สิ่งที่เปลี่ยน

  • A รวม “แบบป้าย” + “โหมด” เป็นแถบ segmented กะทัดรัด — เดิมเป็น 2 การ์ดเต็มความสูง
  • B “ข้อมูล” เปิดค้างเสมอ (ใช้บ่อยสุด)
  • C “โลโก้/ตรา” พับเก็บ default → ลดความสูง คลิกหัวข้อเพื่อกาง
  • D ช่องตัวเลขโลโก้จัดเป็นกริด 2 คอลัมน์ (X/Y/กว้าง/สูง)
  • E ปุ่มสั่งงานท้ายฟอร์ม — Preview เด่น (accent) ที่เหลือเป็นปุ่มรอง

ผลลัพธ์

  • เปิดมาเห็น แบบ+โหมด, ข้อมูล, ปุ่ม — จบในจอเดียว ไม่ต้อง scroll
  • spacing scale เดียว (4/8/12/16) · หัวข้อหมวดสไตล์เดียวกัน · เส้นแบ่งชัด

ลองกดเล่น

  • สลับโหมด “นำเข้ารายชื่อ” → ช่องกรอกเปลี่ยนเป็น ตารางรายชื่อ
  • คลิกหัวข้อ “โลโก้/ตรา” เพื่อกาง/พับ
  • สลับ “แบบ 2” → ช่องตำแหน่ง/หน่วยงานจะซ่อน
  • กดสวิตช์ “ใส่โลโก้บนป้าย”
