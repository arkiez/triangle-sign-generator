# ดีไซน์: ปรับโครงสร้าง UI ฟอร์มฝั่งซ้าย (แนวทาง C)

วันที่: 2026-06-23
สถานะ: รออนุมัติ
ปลายทาง: ใช้เป็นสเปกสำหรับสร้าง mockup ใน Figma ก่อน แล้วค่อยนำไปทำเป็นโค้ด Tkinter

---

## 1. เป้าหมาย

ปรับ **การจัดวาง/โครงสร้าง** ของฟอร์มฝั่งซ้ายในโปรแกรมสร้างป้ายสามเหลี่ยม โดย:

- **ลดการ scroll** — เปิดแอปมาเห็นส่วนที่ใช้บ่อยจบในจอเดียว
- **ลดความรก** — ระยะห่าง/หัวข้อ/เส้นแบ่งสม่ำเสมอ จัดกลุ่มชัด

**ขอบเขต:** คงแนวทางเดิม (panel เดียว: ฟอร์มซ้าย + พรีวิวขวา, ธีม Fluent/Windows 11 Light) ไม่เปลี่ยนเป็นแท็บหรือ wizard ไม่เปลี่ยนสีหลัก/ฟอนต์ ไม่แตะ flow การใช้งาน (ทีละคน / นำเข้า Excel-CSV)

**นอกขอบเขต:** การเปลี่ยนฟีเจอร์, เปลี่ยน engine สร้างเอกสาร, เปลี่ยนพรีวิวฝั่งขวา

---

## 2. โครงสร้างปัจจุบัน (ก่อนปรับ)

ฟอร์มซ้ายเรียงการ์ดแนวตั้งทีละหมวด ต้อง scroll ยาว:

1. การ์ด **แบบป้าย** (radio 2 ตัว: แบบ 1 ชื่อ+ตำแหน่ง/หน่วยงาน, แบบ 2 ชื่ออย่างเดียว)
2. การ์ด **โหมด** (segmented: ทีละคน / นำเข้ารายชื่อ Excel-CSV)
3. การ์ด **ข้อมูล** (ชื่อ, ตำแหน่ง, หน่วยงาน — เรียงทีละบรรทัด)
4. การ์ด **โลโก้/ตรา** (toggle, เลือกรูป/ลบรูป, ตำแหน่ง X/Y, ขนาด — เรียงทีละบรรทัด)
5. (ด้านล่าง) ขนาดฟอนต์ + ปุ่มสั่งงาน (พรีวิว/บันทึก/Word/PDF/พิมพ์)

**ปัญหา:** การ์ดแยกหมวดเต็มความสูงกินที่มาก + ช่องเรียงทีละบรรทัดทำให้สูง → scroll เยอะ และดูรก

## 3. โครงสร้างใหม่ที่เสนอ

### 3.1 ภาพรวม layout (ฝั่งซ้าย จากบนลงล่าง)

```
┌─────────────────────────────────────┐
│ [A] แถบเลือกแบบ+โหมด (กะทัดรัด)        │   ← segmented 2 แถว ไม่ใช่การ์ด
├─────────────────────────────────────┤
│ [B] ▾ ข้อมูล            (เปิดค้างเสมอ) │
│     ชื่อ      [____________________]  │
│     ตำแหน่ง   [____________________]  │
│     หน่วยงาน  [____________________]  │
├─────────────────────────────────────┤
│ [C] ▸ โลโก้/ตรา          (พับ default)│
├─────────────────────────────────────┤
│ [D] ▸ รูปแบบ (ฟอนต์/ขนาด) (พับ default)│
├─────────────────────────────────────┤
│ [E] แถวปุ่มสั่งงาน (ตรึงล่าง/ท้ายฟอร์ม) │
└─────────────────────────────────────┘
```

**ผลลัพธ์เป้าหมาย:** เปิดแอปมาเห็น [A] + [B] (กางอยู่) + [E] จบในจอเดียว ไม่ต้อง scroll
ส่วน [C] โลโก้ และ [D] รูปแบบ กางเมื่อต้องใช้

### 3.2 [A] แถบเลือกแบบ + โหมด (กะทัดรัด)

รวม "แบบป้าย" + "โหมด" จากเดิม 2 การ์ดเต็มความสูง → 2 แถว segmented control เรียงชิดบนสุด ไม่มีกรอบการ์ดหนา

- แถวบน — แบบป้าย: `[ แบบ 1: ชื่อ + ตำแหน่ง/หน่วยงาน | แบบ 2: ชื่ออย่างเดียว ]`
- แถวล่าง — โหมด: `[ ทีละคน | นำเข้ารายชื่อ (Excel/CSV) ]`
- มี label เล็กกำกับซ้ายของแต่ละแถว ("แบบ", "โหมด") สี muted

ประหยัดความสูงเทียบของเดิม ~2 การ์ด

### 3.3 [B][C][D] หมวดพับเก็บได้ (Accordion)

แต่ละหมวดเป็น header กดเปิด/พับได้:

- header สูง 36px, มีไอคอน chevron (▾ เปิด / ▸ พับ) ซ้ายสุด + ชื่อหมวด
- เนื้อหากางใต้ header, มี padding ในตัว
- เส้นแบ่งบาง (1px, `COL_BORDER`) คั่นระหว่างหมวด

สถานะเริ่มต้น:
- **ข้อมูล** — เปิดค้างเสมอ (พับไม่ได้ หรือพับได้แต่ default เปิด)
- **โลโก้/ตรา** — พับ
- **รูปแบบ** — พับ

### 3.4 จัดช่องเป็นกริด 2 คอลัมน์ (ในหมวดโลโก้)

ช่องที่สั้น/เกี่ยวข้องกันให้อยู่แถวเดียวแทนเรียงลง:

```
ตำแหน่ง X [ 100 ]   Y [ 100 ]
ขนาด      [ 100 ]
```

(หมวด "ข้อมูล" คงเป็น 1 คอลัมน์ เพราะช่องยาว; กริด 2 คอลัมน์ใช้กับช่องตัวเลขสั้นในโลโก้/รูปแบบ)

### 3.5 [E] แถวปุ่มสั่งงาน

ปุ่มสั่งงาน (พรีวิว/บันทึก/Word/PDF/พิมพ์) อยู่ท้ายฟอร์ม จัดเป็นแถว/กริดสม่ำเสมอ
ปุ่มหลัก (พรีวิว/บันทึก) ใช้สี accent ปุ่มรองใช้ขอบ `COL_BTN_BORDER`

## 4. Design tokens (ดึงจากโค้ดจริง — ใช้สร้างใน Figma)

### 4.1 สี (Color styles)

| Token | Hex | ใช้กับ |
|---|---|---|
| BG (Mica) | `#f3f3f3` | พื้นหลังหน้าต่าง / แถบหัว |
| Card/Layer | `#ffffff` | พื้นผิวการ์ด/พรีวิว/หมวด |
| Text | `#1b1b1b` | ข้อความหลัก |
| Muted | `#5c5c5c` | label รอง/คำอธิบาย |
| Border | `#e5e5e5` | เส้นขอบ/เส้นแบ่งหมวด |
| Field fill | `#fbfbfb` | พื้นช่องกรอก |
| Row alt | `#fafafa` | แถวสลับในตาราง |
| Button border | `#d6d6d6` | ขอบปุ่มรอง/คอนโทรล |
| Accent | `#0067C0` | ปุ่มหลัก/สถานะเลือก |
| Accent hover | `#1975C5` | hover |
| Accent active | `#005BA1` | pressed |
| Accent soft | `#e6f1fb` | พื้น selected อ่อน |

### 4.2 ฟอนต์ (Text styles) — ฟอนต์ **Kanit**

| สไตล์ | ขนาด | น้ำหนัก | ใช้กับ |
|---|---|---|---|
| Title | 14pt | Bold | หัวหน้าต่าง "สร้างป้ายสามเหลี่ยม" |
| Section head | 11pt | Bold | หัวข้อหมวด (accordion header) |
| Body / control | 10pt | Regular | label ช่อง, ข้อความปุ่ม, ช่องกรอก |
| Body bold | 10pt | Bold | ตัวที่ถูกเลือกใน segmented |
| Small / hint | 8pt | Regular | คำอธิบาย/สถานะ ("ยังไม่ได้เลือกรูป") |

> หมายเหตุ: ในโค้ดมีค่า 2 ชุด (ก่อน/หลัง `_setup_theme`) — ใช้ชุดหลัง (รันจริง) ตามตารางนี้

### 4.3 ระยะห่าง (Spacing scale)

ใช้สเกลเดียวทั้งฟอร์ม: **4 / 8 / 12 / 16 / 24 px**

| ที่ | ค่า |
|---|---|
| Padding ภายในหมวด/การ์ด | 16 |
| ช่องว่างระหว่างหมวด | 12 (มีเส้นแบ่งคั่น) |
| ช่องว่างระหว่างฟิลด์ในหมวด | 8 |
| gutter กริด 2 คอลัมน์ | 12 |
| ความสูง accordion header | 36 |
| ความสูงช่องกรอก/ปุ่ม | 28–32 |
| มุมโค้ง (corner radius) | 6 |

## 5. รายการคอมโพเนนต์ที่ต้องวาดใน Figma

1. **Segmented control** — 2 ตัวเลือก, ตัวเลือก: สถานะปกติ (fill `#fbfbfb` ขอบ `#e0e0e0` ตัวอักษร muted) / สถานะเลือก (fill `#ffffff` ขอบ `#d4d4d4` ตัวอักษร bold เข้ม) — ทำเป็น component + variant
2. **Accordion section** — header (chevron + ชื่อ) + body, variant: expanded / collapsed
3. **Text field** — label + input (fill `#fbfbfb`, ขอบ `#e5e5e5`, radius 6, สูง 28–32)
4. **Number field (สั้น)** — สำหรับกริด 2 คอลัมน์ (X/Y/ขนาด)
5. **Toggle switch** — off (track `#fbfbfb` ขอบ `#8a8a8a`) / on (track `#0067C0`) — สำหรับ "ใส่โลโก้บนป้าย"
6. **Button** — variant: primary (fill accent, text ขาว) / secondary (ขอบ `#d6d6d6`, text เข้ม)
7. **Section divider** — เส้น 1px `#e5e5e5`

---

## 6. Figma build guide (ลำดับแนะนำ)

1. ตั้ง **Color styles** + **Text styles** ตามข้อ 4.1–4.2 ก่อน
2. สร้าง **components** ตามข้อ 5 (ใช้ Auto Layout + variants)
3. ประกอบหน้าจอ (frame กว้างเท่าหน้าต่างจริง ~ซ้าย 520px / ขวา พรีวิว) ตาม layout ข้อ 3.1
4. ทำ 2 state ของฟอร์ม: (ก) เปิดมา default (ข้อมูลกาง, โลโก้/รูปแบบพับ) (ข) กางครบทุกหมวด — เพื่อเช็คว่า default ไม่ scroll
5. ใช้ Auto Layout แนวตั้งกับฟอร์ม เพื่อให้เห็นผลความสูงรวมจริง

## 7. เกณฑ์ความสำเร็จ

- เปิด mockup state default แล้ว [A]+[B]+[E] อยู่ในความสูงจอเดียว (ไม่ scroll)
- ทุกหมวดใช้ spacing scale เดียวกัน, หัวข้อหมวดสไตล์เดียวกัน, มีเส้นแบ่งคั่นชัด
- สี/ฟอนต์ตรงกับ token ในข้อ 4 (ต่อยอดเป็นโค้ด Tkinter ได้ตรง)
